# AllSmartInc/.github

Organization-wide defaults GitHub applies to every AllSmartInc repository that
does not define its own.

- `.github/ISSUE_TEMPLATE/bug.yml` — the Bug form: where it happens, what you see, what
  you expected, on which screen. ditoAi plans and fixes issues filed with it.
- `.github/ISSUE_TEMPLATE/enhancement.yml` — the Enhancement form: the problem, what for,
  how sure you are of the solution. Unless you are sure, ditoAi replies with options first.

The master copy lives in `AllSmartInc/ditoai-core` under `templates/ISSUE_TEMPLATE/`.
Change it there, then copy it here. This repository is public because GitHub
only applies organization defaults from a public `.github` repository; keep
nothing in it that should not be public.
